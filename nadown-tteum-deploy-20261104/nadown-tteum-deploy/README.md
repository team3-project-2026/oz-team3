# 나다운 틈 · 배포용 프로젝트

2026-11-04 캐릭터 반영 버전. HTML·CSS·JavaScript 정적 웹사이트입니다.

## 1. 내 컴퓨터에서 실행
Node.js 20 이상이 설치되어 있다면 이 폴더에서 `npm start`를 실행하고
브라우저에서 http://localhost:8080 을 여세요. 패키지 설치는 필요 없습니다.
또는 Python 3가 있다면 `python -m http.server 8080 --bind 127.0.0.1 --directory dist`로 실행합니다.
종료는 터미널에서 Ctrl+C입니다.
index.html을 더블클릭하는 방식은 JavaScript 모듈 제한 때문에 지원하지 않습니다.

## 2. 웹에 배포
`dist` 폴더 안의 모든 파일을 정적 웹 호스팅의 공개 루트에 올리면 됩니다.
공개 루트 바로 아래에 index.html과 assets 폴더가 있어야 합니다.
별도 빌드 명령, npm install, API 키, 데이터베이스가 필요하지 않습니다.
Git 연동 정적 호스팅에서는 출력 디렉터리를 dist로 지정합니다.
기존 ChatGPT 사이트의 계정 인증·공개 범위는 이 파일에 포함되지 않습니다.
새 호스팅의 공개 범위는 해당 호스팅에서 설정하세요.

## 3. 파일 구성과 수정
- dist/index.html: 기본 화면 구조
- dist/style.css, character.css: 디자인과 캐릭터 배치
- dist/app.js: 화면 전환, 저장, 사용자 동작
- dist/core.js: 추천·실천·회고 규칙
- dist/characters.js: 캐릭터 설정
- dist/assets/characters: 5종 캐릭터 × 2D·3D, 웹 최적화 WebP 10장
- dist/assets: 글꼴, 사진, 아이콘 및 라이선스 안내
- tests/core.test.js: 핵심 규칙 자동 검증 28개 (npm test)
- server.mjs: 의존성 없는 로컬 미리보기 서버

## 4. 기록 보관과 이전
기록은 각 방문자의 브라우저 localStorage에 저장됩니다. 서버 저장·계정 로그인·기기 간 동기화 기능은 없습니다.
이 ZIP에는 사용자의 실제 실천 기록이 들어 있지 않습니다.
기존 사이트에서 설정 → 기록 파일 내려받기를 누른 뒤, 새 주소에서 설정 → 기록 파일 가져오기를 사용하세요.
주소·브라우저가 바뀌면 기록이 자동으로 따라오지 않습니다. 브라우저 데이터를 삭제하기 전에 백업하세요.

## 5. 포함 기능
조건 여러 개와 오늘의 중심 선택, 작은 행동 추천과 이유, 1분 대안, 완료·회고,
내 방법 보관·재사용, 정원 성장, 기록 백업·복원, 틈친구들 2D·3D 전환.

## 6. 검증 범위
기존 핵심 규칙 28개 통과. 파일 참조와 캐릭터 10개 존재, ZIP 무결성을 확인했습니다.
