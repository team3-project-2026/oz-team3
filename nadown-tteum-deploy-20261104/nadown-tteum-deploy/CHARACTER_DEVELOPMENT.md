# 나다운 틈 · 캐릭터 기반 개발 (2026-11-04)

## 기준
- 사용자가 지정한 기획안: https://chatgpt.com/space/page_db8b02e84c0881919f3ac9f27e8b13cc
- 읽은 최신 스냅샷: sequence 33, 총 11개 슬라이드. 이전 발표 초안보다 현재 내용을 우선 적용.
- 초기 핵심 흐름: 복수 조건과 주된 조건 설정 → 큐레이션 행동과 대안 → 완료/선택적 회고 → 오늘의 상태.
- 기획안의 제외 범위에 맞춰 계정·실시간 대화·외부 AI·동기화·공유 게시판을 추가하지 않음.

## 캐릭터 사용
| 캐릭터 | 역할 | 사용하는 곳 |
|---|---|---|
| 틈이 | 작은 시작 안내 | 첫 화면 3D, 행동 추천 |
| 쉼이 | 부담 조정 | 조건 선택 2D, 실천 전 안내, 1분 대안 |
| 모루 | 쉬어가기와 복귀 | 쉬어가는 상태, 회고 건너뛰기, 소개 문구 |
| 느루 | 경험과 방법 모으기 | 회고, 내 방법 |
| 싹이 | 실천 누적 | 완료 상태, 정원 |

- 다섯 친구의 이야기에서 2D/3D 이미지를 전환할 수 있음.
- 원본 10개의 투명 PNG에서 웹용 WebP를 준비함. 2D 512px, 3D 768px. 파일 합계 약 334KB.
- 캐릭터를 돌보지 않았다는 불이익, 연속 달성 경쟁, 실시간 AI 대화 표현은 사용하지 않음.

## 저장 호환과 기록 규칙
- 기존 프로젝트·호스팅 주소·공개 범위를 유지.
- 기존 localStorage 키 nadown-haru-v2, version 2, 일별 기록과 preferences를 유지.
- 선택적 conditions 필드: values 배열과 primary 한 개. 조건을 저장한 재방문은 행동 단계에서 시작.
- 기존 완료·회고 기록을 보존하며, 기존 회고 내용은 확정된 것으로 읽음.
- 새 완료는 completedAt에 최초 시각 기록. 중복 완료·회고 요청은 기존 결과 유지.
- 완료 후 취소/재선택 제거. 회고는 saved/skipped로 한 번 확정.
- 과거의 완료 시각이 없는 기록에는 임의의 시각을 만들지 않음.
- 백업 가져오기에서는 기존 날짜·설정·조건이 우선. 조건만 있는 백업도 가져오기 가능.

## 검증
- 핵심 로직 28개 테스트 통과. 날짜 변경, 구형 기록 호환, 추천 조정, 확정 기록 보호, 조건/백업 병합 포함.
- 실제 브라우저 미리보기: 조건 복수 선택, 주된 조건 전환, 재방문, 시간 변경, 5분→1분 대안, 계획, 쉬어가기/재개, 완료, 회고 저장, 회고 없이 마치기, 방법 저장, 정원, 2D/3D 전환.
- 360·390·600·1024px iframe 및 1348px 데스크톱 미리보기. 가로 넘침 없음. 실제 기기 검증은 아님.
- 모바일 첫 사용 화면의 표시된 버튼·summary는 최소 44×44px 확인.
- 처음 사용 QA는 별도 저장 키로 격리. QA용 HTML/JS는 배포 소스에서 제거.
- 운영 사이트는 로그인 경로를 재시도하지 않고, 네이티브 배포 결과로 게시 성공 확인.
