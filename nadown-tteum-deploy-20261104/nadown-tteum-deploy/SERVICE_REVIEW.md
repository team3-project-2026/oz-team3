# 나다운 하루 서비스 개선 및 차별화 구현

## 초기 확인과 수정

2026년 11월 3일 기준 기존 프로젝트는 저장된 소스 커밋과 배포된 버전이 없었다. 기존 기획의 가치 선택, 작은 행동, 콩과 식물 성장을 작동하는 무료 체험으로 연결했다. 기존 사이트의 이용자 행동을 관찰한 결과는 아니며, 아래 문제는 확인한 기획과 초기 구현 범위에 대한 검토다.

| 문제 | 반영한 수정 | 확인 방법 |
| --- | --- | --- |
| 가치 선택과 원하는 하루 작성이 처음부터 이어져 부담이 크다 | 오늘 필요한 것과 가능한 시간으로 시작하고 하루 문장은 선택 입력으로 변경 | 첫 이용 흐름 |
| 행동의 크기와 사용자의 여유가 연결되지 않는다 | 1분 5분 10분 이내 및 부담 정도로 추천 제한 | 7가지 가치와 시간별 로직 검증 |
| 완료 후 체크만 남고 다음 선택과 연결되지 않는다 | 좋았어요 비슷해요 안 맞아요 및 선택 메모 추가, 안 맞은 행동은 이후 추천 제외 | 추천 로직과 실제 흐름 검증 |
| 완료 중복이나 날짜 경계에서 콩이 부풀 수 있다 | 콩은 완료한 날짜 수에서 계산하고 현지 날짜를 사용 | 반복 완료와 자정 및 미래 날짜 검증 |
| 쉬는 날이 실패처럼 보일 수 있다 | 쉬어간 날과 다시 시작하기 제공, 누적 성장 유지 | 휴식일 및 취소 검증 |
| 저장 및 공용 기능의 범위가 불분명하다 | 브라우저 저장 안내, 기록 내보내기와 안전한 병합, 실제로 작동하는 행동 복사 제공 | 새로고침과 가져오기 검증 |
| 구현하지 않은 공동 기능이나 수익화가 약속될 수 있다 | 가상의 이용자 반응과 결제 및 공동 저장 기능을 노출하지 않음 | 화면 문구 점검 |

## 구현한 범위

오늘의 선택, 42개 행동 추천, 직접 정한 행동, 오늘 계획, 완료 및 취소, 실천 후 느낌, 정원 성장, 최근 7일 기록, 전체 기록, JSON 내보내기 및 가져오기를 제공한다. 입력 문장은 HTML로 실행되지 않도록 출력 시 이스케이프한다. 손상된 저장 데이터는 덮어쓰지 않으며 원본 내려받기를 제공한다. 저장 공간 접근 실패 시에는 현재 세션 유지와 파일 보관 안내를 제공한다.

계정별 서버 저장, 여러 기기 동기화, 실제 친구 응원, 자동 알림과 결제는 포함하지 않는다. 건강이나 행복을 측정하는 점수를 표시하지 않는다. 오늘의 행동 공유는 개인 느낌과 메모를 제외한 텍스트 복사다.

파일 다운로드가 브라우저에서 제한되는 경우를 위해 기록 텍스트 보관 및 가져오기를 제공한다. 파일 다운로드는 요청 사실만 안내하며 브라우저의 저장 완료를 단정하지 않는다.

## 차별화해서 구현한 동작

서비스의 중심을 ‘오늘 필요한 것을 작게 실천하며 나에게 맞는 방법 찾기’로 정리했다. 식물 성장만으로 차별화를 주장하지 않고, 사용자의 실제 반응이 다음 선택을 바꾸는 흐름에 집중했다.

| 상황 | 반영한 동작 |
| --- | --- |
| 행동을 추천받는다 | 오늘 필요한 것, 가능한 시간과 부담 정도, 본인이 남긴 긍정 반응이나 보관 설정에 근거한 추천 이유 표시 |
| 행동이 부담스러웠다 | 기존 5분·10분 행동 28가지 각각에 의미가 이어지는 1분 대안 연결. 기존 행동은 기록일로부터 3일 뒤까지 보류 |
| 시간·장소가 맞지 않았다 | 해당 행동과 관련 1분 대안을 기록일로부터 3일 뒤까지 보류하고 다른 후보 제시. 다음 날부터 자동 허용 |
| 취향에 맞지 않았다 | 직접 다시 추천받기를 선택할 때까지 원래 행동과 관련 대안 제외 |
| 이유 없이 안 맞았다고 남겼다 | 새 기록은 잠시 보류. 이전 버전의 제외 기록은 기존 선택을 존중해 수동 복원까지 유지 |
| 나에게 맞는 방법을 돌아본다 | 내 방법에서 최근 7일의 실제 행동별 실천 수, 느낌 응답 수, 긍정 반응 수를 따로 표시. 느낌 미입력은 부정으로 간주하지 않음 |
| 방법을 다음에도 쓰고 싶다 | 보관과 해제, 오늘 선택으로 불러오기 제공. 행동을 확정하기 전에는 기존 계획을 바꾸지 않음 |
| 제외한 행동을 다시 시도하고 싶다 | 이전 느낌을 삭제하지 않고 추천 허용만 복원 |

오늘 필요한 것은 변할 수 있음을 안내하며, 이를 성격이나 평생의 가치로 진단하지 않는다. 누적 정원과 하루 1회 보상을 유지하고, 화면의 보상 이름은 씨앗으로 정리했다. 추천은 공개된 규칙에 따른 것이며 외부 AI 분석을 사용하지 않는다.

기존 저장 키 `nadown-haru-v2`와 버전 2를 유지했다. 선택 필드인 느낌 이유와 보관·추천 설정을 추가하고, 기존 메모와 기록을 그대로 읽는다. 백업에는 새 설정도 포함하며, 가져오기에서 겹치는 날짜와 설정은 현재 브라우저의 내용을 우선한다.

## 다음 사용자 검증

무료 이용자 20명을 대상으로 처음 행동을 정할 수 있는지, 7일 안에 세 번 돌아오는지, 행동이 너무 크거나 비슷하지 않은지 확인한다. 14일 유료 프로그램은 기본 흐름의 재사용이 확인된 후 별도로 검증한다. 기존 수익화 문서의 가격은 검증 전 가설로 유지한다.

## 검증 결과

자동 검증 24개를 통과했다. 날짜 경계와 중복 보상, 기존 버전 호환, 부담에 따른 1분 대안, 보류 기간, 취향 제외와 명시적 복원, 저장 설정 유지, 시간·여유 필터, 응답 분모, 미래 기록 제외, 사용자 행동의 구분, 가져오기 충돌 처리를 포함한다. `dist/app.js` 구문 검사도 통과했다.

데스크톱 검증 화면의 예시 기록으로 추천 이유, 세 가지 부적합 이유 선택 및 저장, 1분 대안, 보관·재사용→계획→완료→회고 연결을 확인했다. 최근 7일에 같은 행동을 3번 실천하고 느낌은 2번만 남긴 예시가 정확하게 구분됐다. 제외 해제 후에도 과거 부정 응답이 남고, 새로고침과 텍스트 백업에서도 이유·보관 설정·해제 설정·기존 메모가 유지됐다. 실제 운영 이용자 기록은 수정하지 않았다.

검증 브라우저의 파일 다운로드는 실패해 완료 여부를 확인하지 못했다. 파일 대신 기록 텍스트를 보관하고 가져오는 경로를 추가해 확인했다. 모바일 화면은 반응형 스타일을 구현했으나 실기기 확인은 남아 있다.

## 이름과 디자인 반영

2026년 11월 3일 사용자 승인으로 ‘나다운 틈’ 이름과 두 번째 시안의 밝은 바탕·청록색·명조 제목을 반영했다. 퇴근 후 피곤해서 루틴 앱을 중단한 이용자를 초기 가설로 두고, 첫 질문·가능한 시간·시작 버튼의 비중을 높였다. 첫 이용의 기본 시간은 1분이며 기존에 정해둔 시간은 그대로 불러온다.

큰 화분 이미지 대신 작은 햇빛 사진을 첫 화면에 배치하고, 모바일에서는 사진을 숨긴다. 본문과 조작 요소는 실제 텍스트이며 글꼴과 아이콘을 사이트 내부에서 제공한다. 내 방법·정원·기록에도 같은 색과 글꼴을 적용했다. 기존 정원 일러스트와 누적 성장 규칙은 유지했다.

데스크톱 1348×936 화면과 390×844 CSS px의 실제 서비스 프레임에서 확인했다. 모바일 프레임의 일반 스크롤바를 제외한 문서 폭은 375px이다. 가로 넘침 없이 시작 버튼이 아래 메뉴 위에 보였고, 행동 선택→계획→완료→느낌과 이유 저장, 내 방법·정원·기록 이동과 텍스트 백업을 확인했다. 원래의 메모, 6개 검증용 날짜와 보관 설정이 유지되고 중복 보상은 생기지 않았다. 이 기록들은 개발 검증용 예시이며 운영 이용자의 기록이 아니다. 모바일 실기기의 터치·운영체제 검증은 남아 있다.
