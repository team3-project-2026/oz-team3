# 나다운 틈 디자인 기준

## 현재 기준과 이용자 가설

2026-11-04 사용자가 지정한 서비스 기획안(sequence 33)을 따른다. 20~30대를 우선 사용자 가설로 삼되, 전 연령이 회원가입 없이 작은 행동을 선택하도록 돕는다. 낮은 에너지 상태, 일상의 리듬을 다시 찾고 싶은 상황, 가벼운 자기이해가 중심이다. 연령 선호나 서비스 효과를 검증했다는 주장은 하지 않는다. 이전 직장인·30~40대 가설보다 현재 기획안을 우선한다.

복수 행복의 조건 선택 → 오늘의 중심 하나 → 큐레이션된 행동과 작은 대안 → 하루 한 번 완료 → 짧은 회고 또는 건너뛰기 → 누적 실천을 확인하는 흐름이다. 별도 온보딩·계정·대화형 AI·커뮤니티를 추가하지 않는다.

## 이름과 문구

- 이름: 나다운 틈 (이전 이름 나다운 하루)
- 설명: 작게 해보고, 나에게 맞는 방법을 찾는 시간
- 첫 문장: 작은 실천으로, 자라는 나.
- 시작: 오늘의 작은 행동 만나기
- 재방문: 저장된 조건에서 바로 행동 단계로 시작.
- 실천과 정원은 누적하며 연속 기록을 요구하지 않는다.
- 완료 후 행동 변경·취소 없음. 회고도 한 번 확정한다.

## 캐릭터와 시각 기준

기존 청록·아이보리·명조 제목의 차분한 방향에 캐릭터를 연결했다. 큰 장면에는 3D, 작은 안내에는 2D를 사용한다.

## 반응형과 접근성

360·390·600·1024 CSS px iframe과 1348px 데스크톱 미리보기에서 확인했다. 프레임 스크롤바 폭은 제외하며 실제 모바일 기기 시험과 구분한다. 600px 이하에서는 하단 5개 메뉴, 조건 두 열, 작게 배치한 안내 캐릭터를 사용한다. 조건·주된 조건 선택은 키보드 Enter로 조작 가능하다. 표시된 버튼과 summary는 44×44px 이상이고 축소 동작 선호를 존중한다.

## 호환성

기존 프로젝트·주소·공개 범위와 localStorage 키 nadown-haru-v2 및 version 2를 유지한다. 선택적인 conditions, completedAt, reflectionState 필드를 추가한다. 과거 날짜·메모·실천·내 방법을 보존한다. 이전 회고는 확정된 내용으로 읽고, 알 수 없는 과거 완료 시각은 임의로 만들지 않는다. 백업 병합은 현재 기록·설정·조건을 우선한다. 기록은 현재 브라우저에만 저장된다.

구현·검증의 상세 내용은 CHARACTER_DEVELOPMENT.md를 따른다.
