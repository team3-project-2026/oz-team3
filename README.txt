나다운 하루 — HTML · CSS · JavaScript 학습용 프로젝트
======================================================

실행하기
압축 파일을 받았다면 먼저 전체 압축을 풀고 index.html을 더블 클릭하세요.
Chrome 또는 Edge 같은 브라우저에서 바로 열립니다. 별도의 설치나 빌드는
필요하지 않습니다. 이미지가 나오도록 assets 폴더도 함께 보관해 주세요.

세 가지 주요 파일
• index.html: 제목, 문단, 버튼, 선택 영역 등 페이지의 내용과 구조입니다.
• style.css: 색상, 글자, 배치, 선택 상태, 애니메이션과 반응형 화면입니다.
• script.js: 선택, 행동 추천, 완료 처리, 콩 계산, 기록 저장을 담당합니다.

어떻게 동작하나요?
1. 나에게 필요한 행복과 원하는 하루 모습을 선택합니다.
2. 선택에 맞는 작은 행동을 추천합니다. ‘다른 행동 고르기’로 바꿀 수 있어요.
3. 실천 후 ‘완료했어요’를 누르면 콩 한 알을 모읍니다.
4. 기기의 날짜를 기준으로 하루 한 번만 적립합니다. 여러 번 누르거나
   새로고침해도 중복 적립되지 않으며, 다음 날 다시 모을 수 있습니다.
5. 처음에는 0콩에서 시작합니다. 6콩마다 꽃이 피고 다음 목표로 이어집니다.
   누적 콩은 유지되고 유리병은 현재 목표의 콩을 보여줍니다.

기록은 localStorage를 이용해 현재 기기의 브라우저에 저장합니다.
다른 기기와 동기화되지 않으며 브라우저 데이터를 지우면 기록도 삭제됩니다.
브라우저가 저장을 막는 경우 안내를 표시하고 현재 창에서만 기록합니다.
‘함께 응원하기’ 버튼은 시안과 같이 준비 중인 기능으로 비활성화했습니다.

원본 일러스트 활용
assets/reference-art.png는 제공해 주신 793 × 1983px 시안 이미지입니다.
CSS의 .art 영역에서 overflow: hidden과 위치·크기 계산으로 필요한 그림만
보여주는 ‘스프라이트’ 방식을 사용합니다. 글자와 버튼은 이미지가 아니라
실제 HTML이므로 선택·수정·클릭할 수 있습니다. 원본 이미지의 크기를
바꾸면 잘라 보이는 위치도 달라지므로 CSS 좌표를 함께 조정해야 합니다.

직접 수정해 보기
• 문구 바꾸기: index.html에서 해당 글자를 찾아 수정합니다.
• 색 바꾸기: style.css 맨 위 :root의 색상 값을 바꿔 보세요.
• 행동 추가하기: script.js의 ACTIONS에서 [이름, 설명, 그림 종류]를 추가합니다.
  그림 종류는 walk, rest, move, connect 중 하나를 사용합니다.
• 수정한 파일을 저장한 뒤 브라우저를 새로고침해 결과를 확인하세요.

React, TypeScript, 외부 패키지 없이 배운 기초 기술만으로 구성했습니다.
키보드의 Tab과 방향키로 선택할 수 있고, 휴대폰 화면에도 대응합니다.
